# Tablero Kanban de Obra — Puente Provisional

Tablero de control de obra por especialidad (Estructuras, Pintura, Metal Mecánica, Obras Civiles, Seguimiento), con arrastrar y soltar, fechas límite y dependencias entre actividades.

Datos guardados en Firebase Firestore (proyecto `kanban-casmiche`), accesible sin necesidad de iniciar sesión.

Publicado con GitHub Pages.
